WORKSPACE SETUP

Register project

Connect your trainer. Studio runs commands in your project’s directory and keeps each job’s outputs together.

Scratch model training

Initialize fresh weights from a local Transformers config. No pretrained weights or remote model APIs are used.

Paths may be relative to the project directory. Dataset records contain text or messages. Install Studio’s optional [llm] extra in the selected Python environment before training.

Use your project’s Python executable if it has a virtual environment. Arguments run directly, without a shell. Substitutions: {project_root} , {output_dir} .

Environment & output settings

JSONL or CSV with numeric columns. Trainers receive STUDIO_OUTPUT_DIR and, when resuming, STUDIO_RESUME_DIR . Write metrics, checkpoints, and other artifacts into the output directory.

Project files stay in their original directory.
